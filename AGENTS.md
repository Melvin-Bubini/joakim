# Development guidlines
- Always use the latest techniques and ways of writing code with ex @if conditions in html and so on
- Ask questions if anything is unclear
- Always use more and longer code if that means simplicity and understandability for a human. Rather than it being optimized and effective
- Prioritize readablity in the code and simple methods and components with clear purposes
- Always ask questions if anything is unclear rather than taking own decissions
- Do not create methods using abstraction if not nececarry, instead use clear methods with a clear purpose
